# New York Sash — Brand & Style Guide (source: new-york-sash-brand-guidelines.pdf)

Reference doc for `ios/NYSApp/Sources/NYSApp/DesignSystem/`. If the PDF and the Swift
tokens ever disagree, the PDF is the source of truth — update the tokens, not this file's
transcription.

## Logo

- Primary mark: black-and-red wordmark. Never recolored, stretched, rotated, or placed
  over busy photography.
- On dark backgrounds: invert to solid white (including the red). Never place the
  black/red version on a dark background.
- Clear space equal to the height of the "N" in NEW.

## Color palette

| Name | Hex | Usage |
|---|---|---|
| Brand Red | `#B20022` | Logo, primary brand accents |
| Action Red | `#DC3545` | CTAs, buttons, links that need to convert |
| Black | `#000000` | Headlines, footer, primary text |
| White | `#FFFFFF` | Primary background, nav |
| Slate Gray | `#64788C` | Secondary text, muted UI elements |
| Light Gray | `#F8F8F8` | Section backgrounds, cards |

## Typography

- Primary: Aptos (Microsoft system font, not freely licensable for general embedding).
- Fallback for anything outside the main website (decks, one-pagers, ads — and this app):
  **Inter**.
- Headline/subhead weight: 900 (Black), sentence case, no forced uppercase.
- Body weight: 300 (Light).

## UI components

- **Square corners throughout — no rounded buttons or cards.** This is explicit and
  called out twice (once in the checklist).

## Voice & positioning

Family-owned, Central New York since 1989 (Rome, NY founding; Whitesboro since 2001).
Tone: straightforward, trustworthy, neighborly — not salesy. Lead with the homeowner's
problem, back it with 35+ years and the lifetime warranty, close with a low-friction next
step (free quote, call, visit the showroom).

## Pre-ship checklist (from the guide)

- Logo used unaltered, correct light/dark version
- Brand Red or Action Red used correctly for context
- Real project photography, not stock
- Square corners on buttons and cards
- Service area and phone number current
